## 🌟 वैशिष्ट्ये (Features)

1. **भव्य व सन्माननीय प्रवेशद्वार (Opening Screen):**
   - "॥ श्री गणेशाय नमः ॥" आणि "अमृतमय ७६ वा वाढदिवस" सुवर्ण अक्षरांमध्ये.
   - आदरणीय श्री. रवींद्र सदाशिव पवार यांचे सुवर्ण चौकटीतील भव्य छायाचित्र.
   - जन्म तारीख: **१६ ऑक्टोबर १९५० — १६ ऑक्टोबर २०२६**.

2. **इंग्रजी गायन वाढदिवस गीत (Singing Birthday Song in English):**
   - पारंपरिक इंग्रजी सुरांचे गायन (*"Happy Birthday to You"* vocal rendition).
   - ब्राऊझर परवानगीनुसार आपोआप सुरू होण्याचा प्रयत्न (Autoplay).
   - जर ब्राऊझरने स्वयंचलित आवाज अडवला, तर तात्काळ आकर्षक **"वाढदिवसाचं गाणं ऐका"** बटणाची सुविधा.
   - फ्लोटिंग म्युझिक प्लेअर बार: प्ले / पॉझ ("ऐका" / "थांबवा"), म्यूट / अनम्यूट, आवाज पातळी नियंत्रक (Volume Slider) आणि रिअल-टाइम वेळ दर्शक (`0:00 / 0:33`).
   - गाणे स्क्रोलिंग दरम्यान विनाअडथळा सुरू राहते आणि एकदाच वाजून थांबते (अनावश्यक लूपिंग टाळले आहे).

3. **आदराचे वाढदिवस पत्र (Birthday Greeting & Letter):**
   - अस्सल देवनागरी मराठीत नातवंडांकडून आजोबांना कृतज्ञता व्यक्त करणारे भावस्पर्शी पत्र.
   - आजोबांचे शांत, संयमी रूप आणि पवार कुटुंबावरील अखंड आशीर्वादाची सावली याचे सुंदर वर्णन.

4. **पाच कौटुंबिक छायाचित्रांचा गॅलरी अल्बम (Family Photograph Gallery):**
   - `Family Photographs/` फोल्डरमधील सर्व ५ मूळ छायाचित्रांचा वापर (`1000329570.jpg`, `1000329573.jpg`, `1000329574.jpg`, `1000329575.jpg`, `1000329576.jpg`).
   - चेहऱ्यावर कोणताही अवाजवी क्रॉप न होता संपूर्ण छायाचित्र दिसण्याची काळजी (`object-fit: contain`).
   - प्रत्येक छायाचित्रासाठी अर्थपूर्ण मराठी कॅप्शन.
   - **फुलस्क्रीन लाईटबॉक्स (Lightbox Viewer):** मोठे छायाचित्र पाहणे, मागील-पुढील बटणे, कीबोर्ड सपोर्ट (Esc, बाण), आणि मोबाईल स्वाइप सुविधा.

5. **कौटुंबिक आठवणींचा भावस्पर्शी प्रवास (Interactive Memory Carousel):**
   - ५ छायाचित्रांसह कुटुंबाच्या मूल्यांचे ५ विचार (पिढ्यांचे नाते, संस्कार, परंपरा, मायेची सावली, अखंड आशीर्वाद).
   - स्वयंचलित स्लाइडिंग आणि युझर कंट्रोल्स.

6. **खास वाढदिवस सरप्राइझ (Interactive Birthday Surprise):**
   - सुवर्ण पेटीवरील **"खास सरप्राइझ उघडा"** बटणावर क्लिक करताच **"आमचा आधारवड"** हा विशेष गौरव संदेश उघडतो.
   - **झेंडूच्या फुलांच्या पाकळ्यांची उधळण (Marigold Petals Celebration Canvas):** केसरी व पिवळ्या फुलांच्या पाकळ्यांचा वास्तववादी पडणारा वर्षाव.
   - `prefers-reduced-motion` अ‍ॅक्सेसिबिलिटीला पूर्ण सन्मान.

7. **सस्नेह कृतज्ञता आणि आशीर्वाद (Closing Message):**
   - "तुमचं प्रेम, तुमचा आशीर्वाद आणि तुमची साथ आमच्यासाठी अनमोल आहे..." हा निरोपाचा संदेश.
   - "सुरवातीला जा" (Back to Top) स्मूथ स्क्रोल बटण.

## 💻 स्थानिक पातळीवर चालवणे (Run Locally)

संकेतस्थळ स्थानिक पातळीवर पाहण्यासाठी कोणत्याही अतिरिक्त सॉफ्टवेअर किंवा डेटाबेसची गरज नाही:

### पद्धत १: थेट ब्राऊझरमध्ये उघडणे
`index.html` फाईलवर डबल-क्लिक करून ती गुगल क्रोम किंवा एज ब्राऊझरमध्ये उघडा.

### पद्धत २: लोकल सर्व्हरद्वारे (Recommended)
टर्मिनलमध्ये खालीलपैकी एक कमांड चालवा:

```bash
# Node.js द्वारे:
npx serve .
# किंवा
node -e "const http=require('http'),fs=require('fs'),path=require('path');http.createServer((req,res)=>{let p='.'+decodeURIComponent(req.url.split('?')[0]);if(p==='./')p='./index.html';if(fs.existsSync(p)&&fs.statSync(p).isFile()){let m={'.html':'text/html','.css':'text/css','.js':'application/javascript','.mp3':'audio/mpeg','.jpg':'image/jpeg'}[path.extname(p)]||'application/octet-stream';res.writeHead(200,{'Content-Type':m});fs.createReadStream(p).pipe(res);}else{res.writeHead(404);res.end();}}).listen(3000,()=>console.log('Open: http://localhost:3000'));"

# किंवा Python द्वारे:
python -m http.server 3000
```
त्यानंतर ब्राऊझरमध्ये `http://localhost:3000` उघडा.

## 🚀 मोफत पब्लिक होस्टिंग मार्गदर्शिका (Free Public Deployment)

हे संकेतस्थळ पूर्णपणे स्टॅटिक (HTML, CSS, JS) असल्यामुळे ते खालीलपैकी कोणत्याही मोफत सेवांवर २ मिनिटांत ऑनलाईन करता येते:

### पर्याय १: Netlify Drop (सर्वात सोपा पर्याय - कोडिंगची गरज नाही)
1. [app.netlify.com/drop](https://app.netlify.com/drop) या संकेतस्थळावर जा.
2. संपूर्ण `Grandpa Birthday Website` फोल्डर ड्रॅग करून त्या पृष्ठावर ड्रॉप करा.
3. १० सेकंदांत तुमचे संकेतस्थळ मोफत लाईव्ह URL सह (उदा. `https://grandpa-ravindra-pawar-76.netlify.app`) उपलब्ध होईल.

### पर्याय २: GitHub Pages
1. GitHub वर नवीन पब्लिक किंवा प्रायव्हेट रिपॉझिटरी तयार करा.
2. या फोल्डरमधील सर्व फाईल्स (`index.html`, `styles.css`, `app.js`, `assets/`, `Family Photographs/`) पुश करा.
3. रिपॉझिटरीच्या **Settings > Pages** मध्ये जाऊन `main` ब्रँच निवडून **Save** करा.
4. तुमची मोफत लिंक `https://<username>.github.io/<repo-name>/` तयार होईल.

### पर्याय ३: Vercel
1. [vercel.com](https://vercel.com) वर जाऊन "Add New Project" करा.
2. हे फोल्डर निवडून **Deploy** वर क्लिक करा.

> ⚠️ **गोपनीयता सूचना (Privacy Note):**
> संकेतस्थळ सार्वजनिक केल्यावर ज्यांच्याकडे ही लिंक असेल ते सर्वजण कुटुंबाची ही ५ छायाचित्रे पाहू शकतील. आवश्यक असल्यास लिंक फक्त कुटुंबातील सदस्यांसोबत शेअर करा.
